# Auto Delete Linked Lorebook

An extension for [SillyTavern](https://github.com/SillyTavern/SillyTavern) that prompts you to delete a character's linked lorebook when you delete the character, helping to keep your library clean.

## Features
*   Adds a checkbox to the character deletion popup to also delete the linked lorebook.
*   Shows visual indicators (👤 for linked, 🔴 for orphaned) in the lorebook editor dropdown.
*   Prevents orphaned lorebook files from accumulating.

## Installation
1.  Open SillyTavern and go to the **Extensions** menu.
2.  Click **Install extension**.
3.  Paste the following URL: `https://github.com/goop15677-coder/auto-delete-lorebook`
4.  Click **Install**.
